# @devpablocristo/platform-chat-ui

Reusable React chat workspace for product AI assistants.

## Install

```bash
npm install @devpablocristo/platform-chat-ui
```

Import the components and stylesheet:

```tsx
import { ChatWorkspace, createChatAdapter } from "@devpablocristo/platform-chat-ui";
import "@devpablocristo/platform-chat-ui/styles.css";
```
